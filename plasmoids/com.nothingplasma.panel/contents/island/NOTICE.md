# Nothing Island attribution

UI adapted from Omar's `org.omar.nothingisland`, version 1.2, supplied in
`org.omar.nothingisland-v2.plasmoid`. The original metadata declares MIT.
The MIT notice is retained in LICENSE. Nothing KDE adaptations are
GPL-3.0-or-later; the original UI and fonts retain their respective licenses.
Source archive SHA-256: c375b4b49c35c8eb8711b7ce9ca02c6bba418d504d587f85a97b85d8d352a89a.

Adaptations: Turkish/English UI, native Plasma containment/Dialog integration,
existing PipeWire and NetworkManager helpers, native Kicker launcher and
PowerDevil inhibition, recording implementation omitted, light palette,
screen-size constraints. This is an adaptation, not an official Nothing product.
